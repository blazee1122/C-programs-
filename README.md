### Number Programs
- **palindrome.c** - Check if a number is a palindrome

### How to Compile and Run

#### Step 1: Compile the program
```bash
gcc filename.c -o filename
```

#### Step 2: Run the program
```bash
./filename
```

**Example:**
```bash
gcc sum.c -o sum
./sum
```
